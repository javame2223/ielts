# 5 | Nouns & Plurals | 1 | Исчисляемые и неисчисляемые, неправильные множественные формы, much/many, согласование с глаголом
@GOAL Не путать исчисляемые и неисчисляемые существительные (advice, information, research), правильно образовывать множественное число и согласовывать подлежащее со сказуемым — включая коварные *the number of* и *a number of*.
@PLAN
1. Правила множественного числа и неправильные формы.
2. Неисчисляемые существительные, которые в русском исчисляемые.
3. Как «посчитать» неисчисляемое: a piece of, an item of.
4. Much / many, few / little, a lot of, a number of / an amount of.
5. Согласование: the number of, everyone, news, people, police.
6. Практика 1–4 и тест по теме.
@THEORY
### 1. Множественное число
| Правило | Пример |
| + s | trend → trends |
| -s, -sh, -ch, -x, -o → + es | bus → buses, potato → potatoes (но photos, pianos) |
| согласная + y → ies | city → cities (но day → days) |
| -f / -fe → ves | life → lives, half → halves (но roofs, beliefs) |
| неправильные | man → men, woman → women, child → children, person → people, foot → feet, tooth → teeth, mouse → mice |
| не меняются | sheep, fish, species, series, means, aircraft |
| латинские и греческие (академические) | phenomenon → phenomena, criterion → criteria, analysis → analyses, crisis → crises, datum → **data**, medium → **media** |
### 2. Неисчисляемые — без a/an и без -s
Самые частые ловушки для русскоязычных: **advice, information, research, knowledge, evidence, equipment, furniture, luggage, baggage, traffic, accommodation, homework, news, progress, work** (работа), **travel** (путешествия вообще), **money, damage, pollution, transport, software, feedback, scenery**.
✗ She gave me a good advice. → ✓ She gave me some good advice / a piece of advice.
✗ We need more informations. → ✓ We need more information.
✗ Scientists have done many researches. → ✓ Scientists have done a lot of research / many studies.
✗ The news are bad. → ✓ The news is bad.
### 3. Как посчитать
*a piece of advice / information / furniture / evidence, an item of news / clothing, a sheet of paper, a bar of chocolate, a loaf of bread, a means of transport*.
Некоторые слова меняют смысл: *a paper* (газета, статья) — *paper* (бумага); *a glass* (стакан) — *glass* (стекло); *a work of art* — *work*; *an experience* (случай) — *experience* (опыт).
### 4. Слова количества
| С исчисляемыми (мн. ч.) | С неисчисляемыми | С обоими |
| many, few, a few, a number of, several | much, little, a little, an amount of, a great deal of | a lot of, lots of, some, any, plenty of, more, most |
- **few / little** = мало (негативно); **a few / a little** = несколько, немного (позитивно).
- **fewer** (исчисляемые) / **less** (неисчисляемые): *fewer cars, less traffic*.
- **the number of** + мн. ч. → глагол **в ед. ч.**: *The number of students **has** increased.*
- **a number of** (= несколько) + мн. ч. → глагол **во мн. ч.**: *A number of students **have** complained.*
### 5. Согласование с глаголом
- **people, police, cattle** — всегда мн. ч.: *People **are**…, The police **have** arrested…*
- **news, mathematics, economics, physics** — ед. ч.: *Economics **is** difficult.*
- **everyone, everybody, each, every** + ед. ч.: *Every student **has**…*
- **data**: в академическом стиле часто мн. ч. (*the data show*), в современном — ед. ч. (*the data shows*); на экзамене подходят оба.
- Подлежащее стоит до *of*: ***The quality** of the products **has** improved.*
IELTS: в Task 1 — *the number of* (исчисляемые: people, cars) vs *the amount of* (неисчисляемые: water, money, energy). ✗ *the amount of tourists* → ✓ *the number of tourists*. В Task 2 особенно часто ошибаются в *research, advice, knowledge, equipment, evidence*.
